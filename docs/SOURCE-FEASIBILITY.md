## Gate before any live Adapter

1. 在 ticket 留存來源出具的書面授權，明確涵蓋存取、展示、重用方式與範圍；未取得前維持 disabled，不發 live 房源請求。
2. 記錄適用 robots、ToS、允許速率、保留時間、圖片與欄位使用限制；若文件未載明，先補齊授權條款。
3. 只在書面授權範圍內，以授權核定的頻率驗證搜尋、分頁、欄位與 SSR/CSR，保存去個資的可重現證據。
4. 逐來源定義 mapping 和 fixture，更新 Ticket 後再開始 Adapter 實作。

未取得第 1 步授權時，依 Owner 決定暫停新增功能，只保留既有 fixture 示範；不啟動真站 Adapter。禁止 CAPTCHA、登入、Anti-Bot 繞過。
