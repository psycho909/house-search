# UI / UX Design

## Priority

先讓使用者清楚設定條件、比較價格、辨識來源與資料缺口。首版不做商城首頁、Dashboard、大量動畫或地圖主介面。

## Desktop

Header → 搜尋區（縣市、行政區、關鍵字、搜尋）→ 可展開的價格／單價／坪數／格局／屋齡／類型／車位 → 已套用條件 → 結果摘要與來源狀態 → 房源列表。列表每列有標題、總價、單價、建坪、格局、屋齡、地區、來源、更新時間（若有）、前往原站。未知值顯示「未提供」，不顯示 0；圖片沒有使用許可時使用中性 placeholder。

## Mobile

單欄搜尋，縣市和行政區連動；進階條件用底部抽屜且保留套用／清除按鈕；結果卡片先呈現價格、位置和格局，來源連結有足夠觸控面積。開啟抽屜後焦點進入抽屜，關閉後回到觸發按鈕；鍵盤和螢幕閱讀器可操作。

## States and copy

| State | Display |
| --- | --- |
| Searching | 搜尋中與已知的啟用來源；提交鍵避免重複送出 |
| Partial results | 顯示已成功來源的筆數與「部分來源未取得，結果可能不完整」 |
| Source failed / timeout | 逐來源顯示「暫時無法取得／逾時」，保留成功結果與重試整體搜尋入口 |
| No results | 只在所有啟用來源成功且篩選後為零時顯示「沒有符合條件」 |
| No enabled sources | 顯示「目前沒有可用資料來源」及各來源限制，不能說「沒有房屋」 |

筆數應標明是「本次取得且符合條件的 Listing」，非市場總量。疑似相同物件以「可能重複」標籤表示，兩筆仍可各自開啟。篩選可能排除缺欄位物件時，摘要提供簡短提示。

## Interaction acceptance

必填欄位在送出前驗證；切換縣市清除不屬於該市的行政區；價格和坪數顯示單位；進階條件在行動裝置不遮住套用鍵。對 320px 寬螢幕、鍵盤操作及缺欄位 fixture 做人工檢查；正式可用性仍待實作驗收。
